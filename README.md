# Principles of Computer Networks (PCN)

Comprehensive laboratory implementations, socket programming in C, packet sniffing, network simulations in NS-3, and Gemini CLI tools.

---

## Repository Structure

| Folder / File | Description |
| :--- | :--- |
| [**`Excercise1`**](./Excercise1/) | Study of Network Diagnostic Tools & Socket System Calls (TCP & UDP Echo) |
| [**`Excercise2`**](./Excercise2/) | Multi-Client Academic Information Retrieval System (Multithreaded TCP & UDP) |
| [**`Excercise3`**](./Excercise3/) | Implementation of HTTP Web Server & HTTP/HTTPS Client using TCP Sockets |
| [**`Excercise4`**](./Excercise4/) | Inspecting HTTP Packets using Wireshark & C Packet Sniffer |
| [**`Excercise5`**](./Excercise5/) | Simulation of Domain Name Resolution (DNS) Using UDP Sockets |
| [**`Excercise6`**](./Excercise6/) | Implementation of Error Detection using Checksum and CRC |
| [**`Excercise7`**](./Excercise7/) | Flow Control (Stop-and-Wait, Go-Back-N, Selective Repeat) & Distance Vector Routing |
| [**`Excercise8`**](./Excercise8/) | NS-3 Simulation & Performance Analysis of TCP and UDP Traffic |
| [**`Excercise9`**](./Excercise9/) | NS-3 Comparative Analysis of TCP Congestion Control (NewReno, Cubic, BBR) |
| [**`Excercise10`**](./Excercise10/) | NS-3 Comparative Evaluation of Routing Protocols (RIP, OSPF, AODV) under Link Failure |
| [**`Excercise11`**](./Excercise11/) | NS-3 & C Performance Analysis of Heterogeneous Wireless Networks (Wi-Fi, BLE, Zigbee) |
| [**`Models`**](./Models/) | Screenshot records and model references |
| [**`installing gemini_cli.md`**](./installing%20gemini_cli.md) | Guide to installing and configuring Gemini CLI Terminal Chat on Ubuntu |
| [**`gemini`**](./gemini) | API key reference file |
